An entry for the [make.fun bounty "The Funniest Honest Appliance Error"](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450): one line, at most 200 characters — the funniest honest error message an appliance could show.

## The line

> Error 04: drum unbalanced. I have walked across the kitchen and I am not sorry.

A washing machine, flatly reporting the truth: an unbalanced drum makes the machine walk across the floor. It is not sorry.

## How to run

```sh
node main.ts
```

It writes the line to `/output/entry.txt`. Deterministic — the same output on every run. No network, no secrets.
